## XHS 签名方案集成 (Playwright → HTTP + Spider_XHS 签名 JS)

### 背景与决策
- Playwright 代理方案一直无法连通
- 选用 Spider_XHS (cv-cat) v4.0 签名 JS 方案，纯 HTTP + Node.js 子进程

### 执行
1. 复制 JS 签名文件到 `dmshoot/plugins/xiaohongshu/static/` (5 文件, ~4.5MB)
2. npm install crypto-js
3. 创建 `sign.py` (subprocess + Node.js, require() 方式加载)
4. 修改 `adapter.py` — 移除 Playwright/asyncio
5. 修复 WinError 2 (GUI 进程找不到 node) — 使用 shutil.which() + 绝对路径回退
6. 创建 `login.py` — 纯 HTTP QR 扫码登录 (移植 Spider_XHS 登录流程)
7. 更新 `cookie_reader.py` — 用 HTTP 登录替换 Playwright 浏览器登录
8. 更新 `.gitignore` — 添加 node_modules/
9. 安装 qrcode + Pillow — QR 码图片生成
10. 复制 xhs_websectiga_env.js — websectiga 反爬 JSVMP 执行环境

### 登录流程 (无 Playwright)
1. 生成初始 cookies (a1, webId, 反爬: sec_poison_id, websectiga, gid)
2. 获取二维码 URL → qrcode 库生成图片 → 系统图片查看器显示
3. 轮询扫码状态 → 验证登录 → 保存 Cookie 到 DB + 文件

### 结果
- 99/99 测试通过
- Cookie 来源: 环境变量 XHS_COOKIE → 数据库 xhs_cookie → 文件 xhs_cookie.txt
- 扫码登录由程序自动完成
- Node.js 路径自动探测 (shutil.which + 回退列表)
