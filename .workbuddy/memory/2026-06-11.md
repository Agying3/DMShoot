## 核心瓶颈
IM 私信 API 需要移动端 App Token，Web Cookie 有身份验证但无 IM 权限。
唯一可行路径：获取移动端 token 转换机制。

## API 测试结果
| 端点 | 状态 | 说明 |
|------|------|------|
| POST /api/im/v3/chats | 406 code=0 | 成功但无数据 (Web cookie 无 IM 权限) |
| GET /api/im/v3/chats | 200 code=-100 | "登录已过期" (需要移动端 token) |
| GET /api/sns/web/v2/user/me | 200 ✓ | 获取用户ID正常工作 |
| Galaxy /api/galaxy/message/list | 200 ✓ | 仅通知类消息，非 IM 私信 |

## 核心结论
**Web Cookie 无法使用 XHS IM API**。所有 V3 端点返回 406 + 空数据，说明 Web 会话无 IM 权限。IM API 需要移动端 app token（来自 MMKV 的 user_token/idToken），但该 token 在 HTTP REST API 中无法直接作为鉴权凭证使用。

下一步: 需要搞定移动端 token 到 API session 的转换机制，或继续尝试抓包。

## 6/11 最终状态：多路径均堵死
### 困局总结（18:15）
| 路径 | 状态 | 死因 |
|------|------|------|
| WSL2 + 镜像网络 | ❌ | WSL 搞挂，需重装 Ubuntu |
| Docker 容器抓包 | ❌ | 模拟器网桥隔离，无法访问宿主机端口 |

### 核心结论
**XHS IM API 绝对需要移动端 app token。Web Cookie（含 creator token）无论怎么签都拿不到 IM 权限。不抓包拿到移动端 token，XHS IM 功能就无法实现。**
