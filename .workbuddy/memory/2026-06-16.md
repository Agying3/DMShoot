## 图表弹窗滚动重置修复 (20:00)
- **根因**: `_show_modal()` 中 `scroll.setWidgetResizable(False)` + widget `sizeHint()` 返回 `QSize(0, 400)`。widget 不填满 viewport 宽度，每次 layout 重算时 QScrollArea 重新定位 widget，滚动归零
- **修复**: `setWidgetResizable(False)` → `True`，`setMinimumHeight(400)` → `580`（略大于 viewport ~566px）。widget 填满 viewport 宽度，高度固定不变，滚动位置永不重置
- `_modal_open` 守卫保留作为双重保险
