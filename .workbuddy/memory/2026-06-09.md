# 2026-06-09 工作总结

## 小红书 DM API 逆向探测

### 探测范围
系统性探测了 88+ 个 XHS API 端点，覆盖 edith/creator/www 三个子域名，多种路径组合。

### 核心发现

| 端点 | 状态 | 说明 |
|------|------|------|
| `edith.../api/sns/web/v2/user/me` | ✅ 200 | Cookie 有效 |
| `edith.../api/im/redmoji/*` | ✅ 200 | 表情 API，无需签名即可访问 |
| `edith.../api/im/message/history` | ⚠️ 401 | 端点存在，需普通用户 Cookie |
| `creator.../api/galaxy/message/list` | ✅ 200 | 创作者平台通知，无 send 端点 |
| `edith.../api/sns/web/v2/message/*` | ❌ 404 | **adapter 当前使用的端点全部不存在** |
| `www.../message` | ❌ 重定向 | creator Cookie 被重定向到首页 |

### 测试过的认证变体 (对 /api/im/)
- 不同 Referer (creator/www/edith) → 全部 401
- x-user-id header → 401
- Bearer access-token → 401
- 签名 vs 无签名 → 401 一致（不是签名问题）
- 最小 Cookie (仅 web_session+a1) → 401

### Playwright 抓包
- HTTP 请求拦截 + WebSocket 监控 + JS fetch/XHR 拦截
- www.xiaohongshu.com/message 对 creator 账号重定向到首页
- 未捕获到实际 DM API 调用

### 结论
- Galaxy API 可用但只是通知系统，不能回复/发送
- /api/im/ 需要**普通用户**（非 creator）的 Cookie
- Spider_XHS 不支持 DM，adapter 当前使用的端点全 404
