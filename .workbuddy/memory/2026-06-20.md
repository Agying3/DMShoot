## 图表弹窗滚动重置 — 最终方案 (13:17)

### 根因
Qt 内部机制（虚函数表外路径）驱动 QScrollArea 滚动条自动回退，无法从应用层完全阻止。

### 最终方案：消除滚动条
- 内容最大高度 ~350px，viewport ~580px，内容完全在视口内
- **`w.setFixedSize(780, 580)`** — widget 高度 = viewport，永不产生滚动条
- 无需滚动 → 滚动位置回退对用户完全不可见
- 删除所有抗回退检测代码、`_LockedScrollArea` 子类

### 完整演进
1. ❌ `setMinimumHeight` + `setWidgetResizable(False)` — 尺寸未锁定
2. ❌ `setFixedSize(800)` + `setWidgetResizable(True)` — 临界高度
3. ❌ `setFixedSize(800)` + `setWidgetResizable(False)` — widget 锁死但仍有回退
4. ❌ `scroll.ensureVisible = lambda` — Python monkey-patch 无效
5. ❌ `_LockedScrollArea` 子类 — C++ 虚函数覆盖，但 Qt 走其他路径
6. ⚠️ 检测恢复 — 有效但复杂
7. ✅ **`setFixedSize(780, 580)` 无滚动条** — 最简单、稳
